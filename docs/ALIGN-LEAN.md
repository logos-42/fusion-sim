## 3. 环境里哪些是**选择项**(不是形式化结论)

1. **动作集**:{停, η=0.01/0.05/0.20}。形式化里 η 是连续输入,这里离散化是控制问题为了方便(可扩)。
2. **收益口径**:每步红利 = 锁定因子的增量(FC5b 的标度因子)。等价说法:τ_E 的红利照收。
3. **代价口径**:`c·η`(抹平功)或 `c·η·LF(μ)`(功率随锁定因子一起涨)——
   两路都必须过 G6/G7,任何结论都要注明走的是哪一路。
4. **罚分与上限**:窗口关闭 = 罚 5.0 并终止;步数上限 400(n_max)。
5. **奖励归一化**:除以窗口边缘的锁定因子 `1/√(m_e/m_i)`(≈67.5),让量级与 m_e/m_i 无关。

## 4. 参考解怎么来的

`env.analytic_best` 用**穷举**(η × 停步)得到这一类策略的最优回报 —— 它是**策略层**的参考,
不声称是解析物理结论。

## 4.1 v0 的学习器状态(已知缺口,如实登记)

**结论先写在这里:v0 的 RL 学习器没有解决这个控制问题。** 环境、物理与参考解是好的(见 §2/§3),
但"用 RL 学出最优停步"这件事没做到。实测(5 seeds × 400 回合训练 × 20 回合评估):

[work] 已知缺口 · 未解决:线性 Q 未达穷举参考的 95%,并在部分 seed 打爆窗口(closed>0);参考 return ≈ 38.66
[locking] 已知缺口 · 未解决:同上;参考 return ≈ 38.62

- 表格 Q(离散状态):回报 0.29–1.34,对应参考的 0.8%–3.5%;但它**从不打爆窗口**(保守);
- 线性 Q(带 log 余量特征):部分 seed 拿到 24.8(参考的 64%),部分 seed 把窗口打爆 → 回报 −57…−74
  —— 训练在 γ=1、无折扣、长视野(164 步)下有方差/发散问题;
- 穷举参考解本身说明:最优是「中等增益(η=0.05)推到窗口关闭前一步(第 164 步)再停」,
  即 ≈ 38.6 的归一化红利;这个答案**本来就是 TD21 的闭式判据给出的**,不需要 RL 去发现。

**为什么还是要保留这一项(以及 RL 在这里该干什么)**

1. 这份环境的价值在**接口**:它把 TD1–TD21/FC11b/FC5b 变成一个 Gymnasium 环境(可训练、可对照、可复现),
   这是后面所有 AI 工作的地基;
2. RL 在这个问题里的正当用途**不是**"发现最优停步"(那是解析已知的),而是
   **在观测有噪声、参数漂移、模型不确定时保持窗口不开裂** —— 即在非平稳条件下守住 FC11b 的可行性边界。
   v0.1 的方向就是把环境改成"参数未知/时变"(m_e/m_i 漂移、η 的实现值有偏差、抹平代价有噪声),
   那时 RL 与解析最优的差距才有物理意义;
3. 想先要一个"能跑赢参考"的基线,正确的做法是用标准算法(DQN/PPO + 目标网络 + 回报归一化)
   而不是继续调这两个手写学习器。

**v0.1 待办(按优先级)**:① 用标准 RL 库(multi-seed + 回报归一化)复现"不开裂窗口 + 达标回报";
② 加非平稳(参数漂移)版本;③ 把 `RMF 功率 ∝ 锁定因子` 那一项接到场地板账本(01/03 项)上,
让"代价"不再是选择项而是一条算出来的账。
