## 4. 四条结论

**(1) 判决量能回收注入的 μ**（等效 μ vs 真值）：

    注入 1e-4  ⟹ 回收 9.997e-05   （−0.03%）
    注入 1e-3  ⟹ 回收 9.999e-04   （−0.01%）
    注入 1e-2  ⟹ 回收 1.002e-02   （+0.2%）
    注入 0.1   ⟹ 回收 1.020e-01   （+2.0%，小 μ 近似 μ/2 在 0.1 处已退化，属预期）

**(2) 2-D 几何对判决量的系统偏差 ≈ 0**：
ΔR_ci(2D) = R_ci(该几何) − R_ci(共线) ⟹ 非共线 ≤ **4.9e-7**、宽谱 ≤ **7.1e-6**。
⟹ **线性层里 2-D 不给 R_ci 引入偏差**（与 §4b 的 k_y 简并一致）；2-D 的增量只能在非线性段。

**(3) 弦积分/视线诊断对斜模完全失明**：γ_chord 在共线时与真值逐位相等，在非共线/宽谱时**拟合不出**
（该信号里没有 ky≠0 内容）。⟹ 给 G0 的诊断定标结论：**用弦积分测斜模会测到"不增长"**。

**(4) 收敛复核全部通过**：

    收敛_dt半_共线_mu0        γ=0.353553（与 dt=0.01 同值）      新模=2.3e-07
    收敛_dt半_非共线_mu0.01    γ=0.355324（同值）                新模=3.9e-07
    收敛_Ny半_非共线_mu0.01    γ=0.355324（横向分辨率减半同值）    新模=3.3e-05

## 5. dt 的硬限制（必须记住）

dt = 0.01 的点在**非线性段会失稳**：2026-09-30 上午那批所有 dt=0.01 的点 `amp_mode_end = nan`
（跑到 5000 步之前爆掉），而同一配置 dt=0.005 的点跑完全程（末态幅 0.182、r²=0.9999996）。
本表故意只跑到 t = 12（远在非线性段之前），所以 dt=0.01 在这里是安全的。
**做转移/饱和测量必须 dt ≤ 0.005。**

## 6. 与旧表的关系（为什么旧表作废）

旧表（`artifacts/s3_grid/`）的三个问题：

    ① 拟合窗口 [2e-3, 0.05] 不合法 —— 实测该区间窗口引入偏差 ~1e-3，且对 μ=1e-4 远超其效应量；
    ② 那些点 dt=0.01 且跑到 t=50 ⟹ **在非线性段爆掉**（amp_mode_end=nan），拟合 r² 只有 0.85；
    ③ 旧表给出的 γ（0.2696 / 0.2632 / 0.2757 …）**复现不出来**：同一配置重跑给
       A1 γ=0.353468、A2 γ=0.353275、B(t=25) γ=0.353275（与 A2 逐位一致），逐振幅段全部 ≈0.353553。
       旧产物没记 L，事后无法核对配置 —— 这是取证缺口，新驱动器已逐点记 L/IX/几何/窗口。

⟹ 旧表全部数字作废；本表是唯一有效的 2-D 线性基准表。
