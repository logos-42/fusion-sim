"改变净连接数必须非局部" ⟹ 局部/全局平滑操作不该改变离散拓扑量，只有拓扑改变通道（重联）能改。

## 0. 模型与口径（**模型替身 stand-in**，不是装置预测）

    ∂ψ/∂t + {φ, ψ} = η(x,y)·∇²ψ − ν₄·∇⁴ψ         {a,b} = ∂ₓa ∂_y b − ∂_y a ∂ₓb

- ψ = 通量函数；理想极限（η=0）⟹ ψ 被**平流** ⟹ 等值线拓扑（岛的分合）严格不变
  ⟹ 因此下面"S3-1 全部不变"是**理想平流的数学推论 + 离散化体检**，**不是发现**（页内并登记为门，防止被当成果吹）。
- 拓扑改变通道 = 电阻扩散项 η∇²ψ（2-D 里的重联通道）：**只在两岛之间的窄带开**。
- 离散不变量：**固定阈值下超水平集 {ψ > thr} 的连通分量数**（并查集，**带周期连通**）。
- 2-D 岛结构是 3-D 净连接数（辫词指数和）的**替身**；两者不是同一个量（诚实边界见 §4）。

## 3. S3-2 拓扑改变通道：**未分离开（如实登记）**

设 sep = 2.0、η 只在两岛之间 0.6 宽的窄带（η₀ = 5e−2）、t_end = 15、thr = 0.5×初始峰：

    桥接比（鞍部/峰）：0.088 → 0.198（t = 0 → 1.0，单调升）
    峰值/阈值：        2.00 → 1.76（t = 0 → 1.0，单调降）
    N 分量：2 →（t ≳ 5 后）0

诊断：**合并与衰减的时间尺度纠缠**。按上面两个速率外推，鞍部要越过阈值（比值 0.5）约需 t ≈ 17，
而峰值在 t ≈ 5.4 就掉到阈值以下 ⟹ 计数是"**振幅衰减消失**（2→0）"，不是"鞍部升过阈值（2→1）"。
⟹ 当前参数下**看不到干净的合并窗口**；要分离两者需要更窄的电阻带（让峰值衰得更慢）或更小的 sep。
参数扫描（sep × η₀ × 阈值比 六组）正在进行，结果按"扫描结论"另行登记 —— **本步不假装已解决**。

## 5. 诚实边界

1. 2-D 岛合并是 3-D 净连接数的**替身**，替代关系是**假设**，非定理。
2. §2 的不变性是理想平流的推论；本步只是把它在离散化里验了一遍。
3. §3 未分离成功（衰减与合并纠缠），已如实登记，**没有**把它写成"重联确认"。
4. 阈值代价的数量级口径（代码单位 → 装置）尚缺一句可辩护的归一化（上游解析区间 1e6–1e9 J）。
5. 本步**不触及**上游的"第二输入缺口"（拓扑事件从哪来、代价多少）；只做了"局部 vs 全局"这一支的判决。
