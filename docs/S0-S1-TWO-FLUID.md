# S0/S1 —— 双流系统（1-D 冷两流 / 双反向流 + μ 可关闭）

本档是 hushfusion 公开**判决漏斗 G0** 的执行层记录。「双流」在本仓分三个意思，勿混：

| 名 | 是什么 | 状态 |
|---|---|---|
| (a) 两流体等离子体 | 离子 + 电子两流体（Hall-MHD） | 本档 S0/S1 只做了**静电极限**（冷束），Hall-MHD 在 S2 |
| (b) 双反向环流 | 两束反向漂移的载流子 | **已做**（本档主体） |
| (c) 双流不稳定性 | 反向流之间的 two-stream | **已做判据**（T6），动理学版本在 S4 |

## 1. 代码与门

- `gym_mu_frc/two_fluid_1d.py` —— S0 解析谱（介电函数多项式根 + 手推闭式）+ S1 时域谱方法求解器（RK4，FFT Poisson，2/3 去混叠）。μ 的注入是 `m → m(1−μ)`，**可一键关闭**（`mu = 0`）。
- `scripts/verify_plan_gates.py` —— 门 T0–T7 + S2 待办登记 ⟹ `artifacts/plan_s0_s1.json`。
- `make plan`（`make test` 里也跑）。

## 2. 闭式（推导，不是背的）

对称冷双束（各 n/2，速度 ±v₀）、单位 ω_pe = v₀ = 1：

    (ω² − k²v₀²)² = ω_p²(ω² + k²v₀²)
    ⟹ γ_max = ω_p/(2√2) = 0.353553,  k* v₀ = √(3/8)·ω_p = 0.612372
    不稳定带：k v₀ < ω_p

实测三条独立路线互相验证（T0/T1/T2）：

| 路线 | 与闭式/彼此的偏差 |
|---|---|
| 手推闭式 vs 数值扫 k | k* **2.4e−8**、γ_max **5.4e−11** |
| 4×4 线性化 vs 介电函数根 | 逐根距离 **6.7e−16**（差 e^{∓iωt} 约定） |
| 时域谱方法 vs 解析（本征矢初值） | **2.7e−11**，R² = 1.00000，dt 减半漂移 4.7e−11 |

## 3. 关键结论（G0 要的「零假设 + 分辨率要求」）

**签名可见性定理**：把**所有**物种质量同倍重标 m → m(1−μ) 等价于时间重标定 ⟹
**任何同源速率之比（γ/ω_p、γ/Ω_ci）带零签名**（数值验到 1.6e−11 的散布）；只有相对
**外部时钟**（RMF 驱动频率 / 回路频率 / 壁钟）的**绝对速率**才带 1/√(1−μ)；只有
**物种间不匹配**（μ_e ≠ μ_i）才会在跨尺度比值里露头。

⟹ **对 G1（生死门）的直接后果**：诊断不能走「增长率比值」这条路，必须走绝对频率比对；
而 μ ~ 1e−4 档要求的单发相对精度是 **1.67e−5（3σ）**：

| μ | δγ/γ = 1/√(1−μ) − 1 | 3σ 单发所需相对精度 | 单发精度 1e−3 时所需发数 |
|---|---|---|---|
| 1e−4 | 5.00e−5 | 1.67e−5 | **3 599** |
| 1e−3 | 5.00e−4 | 1.67e−4 | 36 |
| 1e−2 | 5.04e−3 | 1.68e−3 | 0.35（1 发足够） |
| 1e−1 | 5.41e−2 | 1.80e−2 | 0.003（1 发足够） |

这是**坏消息提前到达**：G1 想抓 μ ~ 1e−4 的签名，靠增长率需要约 3600 发 —— 桌面判据台
多半到不了。要么 G1 换观测量（相位/阈值穿越/绝对频率比对），要么把第一档的 μ 期望抬到
1e−3 以上。这正是 G0 该在花钱之前说出来的话。

**双反向流的工程约束（T6）**：D 等离子体 n = 1e20 m⁻³、T_e = 100 eV、L = 1 m ⟹
c_s = 6.95e4 m/s、ω_pi = 9.34e9 rad/s、冷两流阈值 v₀ ≳ 1.49e9 m/s（比 c_s 高 4 个量级）
⟹ **绑定约束是马赫数 < 1**（离子声速档，教科书口径，本模块未复算）。RMF 若故意用两流
不稳定性当加热源，那就必须**进账**，不是忽略。

## 4. 诚实边界

- 冷静电极限：无 Debye 屏蔽、无动理学阻尼、无非线性饱和（S4 才上动理学）。
- 谱一致性只在同一 k 上验过。
- 「马赫 < 1」是教科书口径，**本模块没有复算**（要复算得上热电子/动理学模型）。
- S2 的四项判决量**未做**（见门输出的 TODO 行）：R_ci 零假设基准表、诊断分辨率要求（绝对时钟口径）、
  双流阈值曲线 (μ, B, n)、排序不可交换可观测性、盲样试验。
