## 1. 实验定义（先说清判什么）

G0 交付物原文 = 「标准 MHD 预测 **R_ci = 0** 的解析/数值基准 + 诊断方案定标」。
S0/S1 交了 1-D 解析与三条互验；S2 交了零假设底与仪器规格。**S3 = 把零假设底从 1-D 推到 2-D**：

    R_ci := γ_实测/γ_标准 − 1       （等效 μ = 2·R_ci）

2-D 不是"更精细的 1-D"，它带来三个 1-D 里**不存在**的自由度：

    (a) 斜模 (k_x, k_y ≠ 0)：零点偏移与不稳定带形状
    (b) 横向/丝化通道：能量从纵向流进横向（1-D 恒为零）
    (c) 2-D 诊断的空间平均（弦/视线积分）对 R_ci 的额外压低

## 4b. ★ 设计更正：**「斜角」轴在物理上是空的**

首跑斜模扫描时三组全部返回 nan。查下去发现**不是代码问题，是设计做错了**；
而且我第一版把归因写错了一处，下面已更正：

1. ~~「我挑的斜模出了不稳定带」~~ **【归因更正】**：不稳定带的判据是 **k_x**（不是 |k|）。
   `(4,4)` 的 k_x = 0.866 < ω_p/v₀ = 1，**其实在带内、而且确实增长** —— 证据来自同一个后台
   任务的带外对照：它 12 个时间单位里模幅从 0.82 涨到 **10.48**（12.8×）；
   而 `(6,0)`（k_x = 1.299）从 0.82 掉到 0.547 —— 那才是真稳定。
   拿 |k| = 1.225 去判「出带」是错的（色散关系只含 k_x，见下条）。
   ⟹ **nan 只有一个原因：模幅归一化不一致（§7 的「模幅归一化」条）**，与带内外无关。
2. **真正的物理更正：线性层 γ 与 k_y 无关**。推一遍就知道：

       ε(ω,k) = 1 − Σ_s ω_ps² / (ω − k·u₀ₛ)²        （冷、静电；u₀ₛ = ±v₀ x̂）
       ⟹ **只有 k·u₀ = k_x v₀ 进入色散关系**，k_y 只改变横向空间依赖，不改增长率。

   ⟹ **2-D 求解器的线性层没有任何新物理 —— 它在数学上就是 1-D 的复述**（T2D-0 回归门
   恰好就是这个物理事实的数值版本，不只是代码检查）。
   线性基准表因此**可以直接用 1-D 的结果**（S2 已有），2-D 的存在理由必须落在**非线性段**。

**2-D 真正的三个可测内容（都需要跑到非线性段）**：

    (a) 横向能量转移 / 丝化：需要**非共线多种子**（如 (4,0) + (0,4) 两个模同时给）。
        单模共线初值下 ky≠0 能量被非线性的卷积结构**精确保持为 0**（已实测：污染 = 0.0e+00）
        ⟹ **单模 2-D 实验是空的**，这是本条更正的核心。
    (b) 2-D 诊断效应：真模幅 vs 视线积分 / 弦平均信号之比 —— 直接进 R_ci 的零假设底。
    (c) 饱和水平：1-D 与 2-D 的饱和振幅/时间不同 ⟹ 检验拟合窗口与绝对振幅阈值是否仍合法。

**修订后的网格与机时**（要跑到 t ≈ 40–60 ⟹ 5000 步/点）：

    网格： μ ∈ {0, 1e−4, 1e−3, 1e−2, 1e−1}（5） × 种子几何 ∈ {共线对照, 非共线双模, 宽谱}（3） = 15 点
          × 5000 步 = 75 000 步
    + 收敛复核（dt 减半 / N 加倍 × 2 点）≈ +20% ⟹ 90 000 步

    屏幕档 N=256²   90 000 步 ÷ 47.5 步/s  =   32 分钟
    生产档 N=512²   90 000 步 ÷  8.09 步/s =  3.1 小时
    （加双 seed ⟹ ×2）

## 4d. 横向能量转移的首个证据（N=64，粗网格）

种子 (4,2) + (4,−2)（两者的 k_x = 0.866 都在带内），末态能量前 8 的模：

    模 (ix,iy)              能量         判读
    (60,62) (4,2) (60,2) (4,62)   1.1459e+05   种子（实场里每个种子占 ±k 两处）
    ( 8, 0) (56, 0)               1.2709e+03   新模 = 种子的 1.1%
    ( 8, 4) (56,60)               6.2832e+02   新模 = 种子的 0.55%

新模落点**正是二次耦合的预言**：4+4 = 8、2+2 ∈ {0, 4} ⟹ (8,0) 与 (8,4)。
对照：单模共线 (4,0) 的横向占比恒 = 0.000000e+00（五个时间点全部为 0）。

边界：N=64 粗网格、μ=0 单点、只到 t=30（未饱和）；定量与 μ 依赖留给段 2。

## 4e. 转移的两条观测量陷阱（做 2-D 转移测量前必读）

1. **「横向占比」不能直接用**：若种子本身就是 ky ≠ 0 的模（非共线实验必然如此），
   它从 t=0 就 ≈ 1.0 —— 把**种子自己**算成了转移。实测：非共线组 t=4 就是 1.000000e+00。
2. **「新模占比」必须把共轭伙伴一起减掉**：实场满足 ρ̂[−i,−j] = conj(ρ̂[i,j])，
   种一个模实际占 ±k 两处。只减一个的话 t=0 给出 **0.5 的假基线**（实测正是 5.000000e-01）。
   修后 t=0 = 0.000e+00（单模 −2.2e−16 = 舍入）。

⟹ 判「有没有转移」的正确姿势：**用 `top_modes()` 直接看谱**（哪些模出现了、能量多少），
再用 `new_mode_fraction`（含共轭修正）做时间曲线。

## 7. 已知陷阱（写完代码前先读）

- 谱方法：**散度用乘积形式（`∂x(n vx)`），对流必须先求导再乘（`vx ∂x f`）** —— 两者形式不同，混了就多算一项。
- **模幅归一化**：2-D 的 `|fft2(rho)[ix,iy]|` 是 1-D `|fft(rho)[mode]|` 的 **Ny 倍** ⟹ 必须除 Ny，
  否则拟合窗口阈值整体落空（症状：窗口点 = 0、拟合 nan，会被误读成"没有增长"）。
  修好后实测两端口径逐位相等（3.208541540970e−03，相对差 0.00e+00）。
- **拟合用模幅，不要用实空间最大值**：实测模幅拟合 Δγ = 3.3e−9（几乎命中解析值），
  用实空间最大值拟合偏 7e−4（后者含谐波与其它模的贡献）。
- 拟合窗口按**绝对振幅**划（20×seed → 0.05）；按末态百分比划会把非线性段算进斜率。
- 初值必须用**不稳定本征矢**（只扰密度会出拍频，早期 γ 为负）。
- Poisson 符号：`∇²φ = −ρ/ε0 ⟹ φ̂ = +ρ̂/(ε0k²)`（正号）。
- **冷模型的带内判据是 k v₀ < ω_p，且 v₀ 沿 x ⟹ 判据看 k_x**；斜模别拿 |k| 判带内外
  （`(4,4)` |k|=1.225 > 1 但 k_x=0.866 在带内，实测照样增长；`(6,0)` k_x=1.299 才是真稳定）。
- 去混叠两端的约定要一致（1-D 的 `cut=int(N/3)` 与 2-D 的 `|i| ≤ N/3` 差一个模；
  线性区无能量落在截断处，所以不影响回归门，但跨分辨率比较时要留意）。
