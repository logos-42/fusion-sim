# S3 计划 —— 2-D 两流体与 G0 的零假设基准表

本文回答「完成仿真实验要多久」。**所有机时数字来自实测算，不是估。**
成本公式：`机时 = 点数 × 每点步数 ÷ 实测总吞吐`。

## 1. 实验定义（先说清判什么）

G0 交付物原文 = 「标准 MHD 预测 **R_ci = 0** 的解析/数值基准 + 诊断方案定标」。
S0/S1 交了 1-D 解析与三条互验；S2 交了零假设底与仪器规格。**S3 = 把零假设底从 1-D 推到 2-D**：

    R_ci := γ_实测/γ_标准 − 1       （等效 μ = 2·R_ci）

2-D 不是"更精细的 1-D"，它带来三个 1-D 里**不存在**的自由度：

    (a) 斜模 (k_x, k_y ≠ 0)：零点偏移与不稳定带形状
    (b) 横向/丝化通道：能量从纵向流进横向（1-D 恒为零）
    (c) 2-D 诊断的空间平均（弦/视线积分）对 R_ci 的额外压低

## 2. 分辨率设计（S2 的成果直接给出）

## 4. 算例网格：**n 的扫描是冗余的**

归一化单位下（ω_pe = v0 = 1），密度 n 只是把时间单位整体重标 —— 同一物理。
n 只通过 SI 换算进入工程约束（已在 S2 的 `field_required` / `ion_stream_constraint` 处理）。
⟹ 2-D 的新自由度只有 **(μ, 斜角)**，不是 (μ, n, 斜角)。这砍掉了 2/3 的机时。

    基准表： μ ∈ {0, 1e−4, 1e−3, 1e−2, 1e−1}  ×  斜模 k_y/k_x ∈ {0, 0.5, 1.0}   = 15 点
    收敛复核：dt 减半 + N 加倍，各在 2 个代表点上                          =  4 点
                                                          合计          = 19 点 × 2000 步

## 5. 机时预算（按第 3 节实测吞吐）

    屏幕档 N=256²   38 000 步 ÷ 47.5 步/s  =     13.3 分钟
    生产档 N=512²   38 000 步 ÷  8.09 步/s =     78  分钟
    加 dt/N 复核            +25%            ⟹ 17 分钟 / 98 分钟
    若每个配置加 1 个初值相位独立实现（双 seed）⟹ ×2 ⟹ 34 分钟 / 3.3 小时

**结论：纯机时 15 分钟（屏幕档）～ 1.6 小时（生产档）；双 seed 生产档 3.3 小时。**
全部可后台跑，不占人工。

**唯一的真风险是段 1 的求解器正确性，不是算力** —— 已经验证：段 1 一上来就抓到
`_adv` 把「乘积的谱导数」当成对流项（`∂x(vx·f) = vx∂x f + f∂x vx`，多算一项），
表现是 2-D 先涨后跌（拍频）而 1-D 正常增长；密度方程的形式本来是对的，所以 `dn` 逐位一致而
`dv` 差 3.2×，差量恰好等于多出来的 `vx∂x vx` —— 这条也被写进 skill 的陷阱清单。

## 7. 已知陷阱（写完代码前先读）

- 谱方法：**散度用乘积形式（`∂x(n vx)`），对流必须先求导再乘（`vx ∂x f`）** —— 两者形式不同，混了就多算一项。
- 拟合窗口按**绝对振幅**划（20×seed → 0.05）；按末态百分比划会把非线性段算进斜率。
- 初值必须用**不稳定本征矢**（只扰密度会出拍频，早期 γ 为负）。
- Poisson 符号：`∇²φ = −ρ/ε0 ⟹ φ̂ = +ρ̂/(ε0k²)`（正号）。
- 去混叠两端的约定要一致（1-D 的 `cut=int(N/3)` 与 2-D 的 `|i| ≤ N/3` 差一个模；
  线性区无能量落在截断处，所以不影响回归门，但跨分辨率比较时要留意）。
