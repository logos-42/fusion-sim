# S2 —— 双流系统的判决量（零假设底 / 阈值 / 排序 / 盲样）

`make s2` ⟹ `artifacts/s2_verdicts.json`（9 门，约 150 s）。接 S0/S1（`gym_mu_frc/two_fluid_1d`）。

## 0. 判决量的定义（先说清判什么）

    R_ci := γ_实测/γ_标准 − 1         （绝对速率相对标准两流预测的相对超出量）

- μ = 0（标准 MHD）⟹ 真值 **R_ci = 0**；
- μ ≠ 0 ⟹ 真值 = 1/√(1−μ) − 1 ≈ μ/2。
- 本档报告的是**零假设底**：标准物理下 R_ci 会被哪些系统性效应顶成非零。为便于与 μ 阶梯比，
  统一换算成**等效 μ = 2·R_ci**。

## 1. 首跑纠正（三条预测与实测相反，按实测改门）

| 项 | 我先前的预测 | 实测 | 修正后的结论 |
|---|---|---|---|
| 窗口上沿（fit_hi=0.2） | 主系统误差（≫1e−2） | **2.5e−8** | 不是主误差。先前那个 −14% 来自**拍频**（初值没取本征矢），不是非线性 |
| 噪声底 | σ=1% ⟹ 1e−3 量级 | **1.37e−2** | 比预测大一档（拟合窗口短、e 折数只有 ~3） |
| 协议漂移（sloppy 窗口） | 造假阳性 | 假阳性 **0**，检出率归零 | 方向相反：漂移**压低** γ̂ ⟹ 失败模式是**漏检**（保守方向） |

## 2. 主系统误差是 **k 量化**（设计规则，不是调参）

周期性把 k 钉在半格 ±Δk（Δk = π/L）上；γ 对 k 的导数决定它放大成多大误差：

| 工作点 | dγ/dk | 等效 μ |
|---|---|---|
| 离峰（k = 0.866，随手的盒长） | −3.1 | **6.3e−1** ← 比任何 μ 签名都大 |
| 峰上（k = k* = √(3/8)ω_p/v₀，dγ/dk = 0） | −4.3e−7 | 6.3e−2（只剩二阶项） |
| 峰上 + 盒长 m 个波长 | 0 | ∝ 1/m²（**log-log 斜率实测 −2.000**） |

⟹ **设计规则**：① 工作点必须放在**色散峰**（k ≈ k*）—— 一阶项消失；② 剩下的二阶项只能靠**盒长**或
**独立测 k** 解决：μ = 1e−3 档需要 **m ≳ 34 个波长**（L ≳ 350，在 v₀/ω_p 单位下）。

## 3. 仪器规格（判决量的直接产物）

噪声加在**诊断信号**（模式振幅时间序列）上；实测噪声底**严格 ∝ σ**（三段比值 10.0019 / 10.0001）：

| σ_signal | γ̂ 相对标准差 | 3σ 等效 μ |
|---|---|---|
| 1e−2 | 2.28e−3 | 1.37e−2 |
| 1e−3 | 2.28e−4 | 1.37e−3 |
| 1e−4 | 2.28e−5 | 1.37e−4 |

反推规格（线性外推，基准 σ=1e−2 ⟹ 3σ 等效 μ = 1.37e−2）：

| μ 目标 | 需要的 σ_signal（3σ） |
|---|---|
| 1e−4 | **≤ 7.3e−5** |
| 1e−3 | ≤ 7.3e−4 |
| 1e−2 | ≤ 7.3e−3 |

## 4. 盲样（阈值标定 + 协议漂移对照）

- 阈值由 **fixed 协议**在 μ=0 集合上标定（5% 分位，等效 μ = 8.11e−3）。
- fixed：假阳性 **4.2%**；检出率 μ=1e−2 → **100%**，μ=1e−3 → **17%**。
- sloppy（窗口随手取到 0.2）：假阳性 0、检出率全归零 ⟹ **协议漂移吃掉全部灵敏度**（不是造假阳性）。
- 随机基线检出率 50%（对照）。

## 5. 阈值闭合（μ 的两面）

- 热压支：B_req 与 μ **精确无关**（比值 1.000000000000）；
- 流动支：B_req/B₀ 按 √(1−μ) 降（μ=1e−1 时 0.9742）；
- 代价面：μ > 0 使离子两流不稳阈值 v₀ < ω_pi/k **变宽**（μ=0：4.70e8 → μ=1e−1：4.96e8 m/s）。
  ⟹ μ 有好处（场需求↓）也有代价（反向流更易两流失稳），可行域由两者交界给出。

## 6. 排序不可交换（TD15–TD17 的仿真版）：**未达标，如实登记**

离散算子 D（交变驱动）× C（压缩）：Δ = |F(D→C) − F(C→D)|/scale

| μ | Δ |
|---|---|
| 0 | 1.985e−3 |
| 1e−2 | 1.897e−3 |
| 1e−1 | 1.057e−3 |

- **数值底极差 = 9.66e−4** ⟹ 基线/底 = **2.05 < 3** ⟹ 按判定线记为**未达标**：
  先把 Δ 收敛（更高分辨率 / 更细 dt），再谈能不能当第二通道。
- μ 依赖部分（1e−1 − 0）= −9.28e−4，虽然大，但和数值底同量级 ⟹ 目前**不可用**。

## 8. 诚实边界

- 噪声加在诊断信号上，**没有**重跑物理（除非另开一版）；
- 压缩/驱动是**离散算子**，所以"排序"检的是算子序列，不是时间积分器；
- 双流阈值用冷静电判据（k v₀ < ω_p），磁场只通过平衡关系进入，**没有**动理学磁化效应。

## 9. 口径变更登记（2026-09-30，来自 ProjectionPhysics 的非局部性结论）

**上游事实（不是本仓的结论）**：ProjectionPhysics 的 `theory-mu-topology.md`（提交 77c794f）
接受了"**改变净连接数必须非局部**"这一支，并把"非局部"落成可算量：
局部变形（braid 关系式 / 共轭 / 循环置换）**不改**辫词指数和 e；只有**加股（拓扑事件）/ 改幂次**才改 e ±1。
即：μ 不是连续可调量，而是**离散的配置标签**；代价不是微分价格，而是**一次拓扑事件的阈值能量**
（该仓量级：1e6–1e9 J，整管口径 0.6 GJ = 装置级）。

**对本仓 S2 判据的影响（只改口径，不改数字）**：

| 本页原来的口径 | 变更后的读法 |
|---|---|
| σ_signal ≤ 7.3e−4 才能 3σ 分辨 μ = 1e−3 | 这是**"若 μ 连续可调"**的仪器精度要求；在非局部支下，μ 的分辨率不来自仪器精度，而来自**能实现多少个不同配置**（配置枚举） |
| μ 阶梯 1e−4 / 1e−3 / 1e−2 是连续的档位 | 改成**离散配置表**：每个配置给一个确定的 μ 值（由 e 与 gross 定），阶梯退化为"配置序号" |
| R_ci = γ/γ_std − 1 作为**连续**判决量 | 量不变（仍然可测），但它现在测的是"当前配置落在哪个 μ 值上"，而不是"μ 被调到多少" |

**两者关系**：S2 的精度表**并不作废** —— 它回答的是"如果 μ 能连续拨，要多好的诊断"；
新口径回答的是"若 μ 只能换配置，判决量就变成配置识别"。两个口径要一起写进诊断需求单，
不许只引用其中一个。⟹ 本页 §1 的判决量定义与 §3 的精度表**保持不变**，仅加此登记。

**尚未做**：把上面的"配置枚举"口径落成一张可执行的配置表（哪个实验配置对应哪个 e / μ）；
以及 S3 判决实验（局部操作不该改 μ 的量子、全局重联式能改；局部能改即证伪上游那一支）——
